# Code of Conduct

gVisor follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

The Code of Conduct applies in all gVisor project spaces, such as the
repository, issues, pull requests, mailing lists, Slack channels, and community
meetings. The CNCF Code of Conduct defines its full scope.
